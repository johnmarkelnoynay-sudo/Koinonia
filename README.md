# Koinonia CAFE

Café website for Koinonia CAFE — golden mornings, soft conversations, slow afternoons.

## Structure

- `Koi/index.html` — main site (single-page, self-contained)
- `Koi/Koinonia CAFE.html` — original file

## Run locally

Open `Koi/index.html` in any browser. No build step required.

## Deploy (GitHub Pages)

This repo ships a GitHub Actions workflow (`.github/workflows/pages.yml`) that publishes the `Koi/` folder to GitHub Pages on every push to `main`.

Enable Pages in the repo settings: **Settings → Pages → Source → GitHub Actions**.
